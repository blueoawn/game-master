# File Locations Reference

Quick reference for where everything is in the new architecture.

## Frontend Build & Serving

### Development (Vite dev server)
- **Entry Point**: `frontend/public/index.html`
- **Main Script**: `frontend/src/main.ts`
- **Dev Server**: `http://localhost:3000` (run with `npm run dev`)
- **Build Command**: `npm run build` (in `frontend/` directory)

### Production (Flask serves)
- **Built Files**: `frontend/dist/` (created by `npm run build`)
- **Flask Serves**: `frontend/dist/index.html` via route `/`
- **Static Assets**: `frontend/dist/assets/` (auto-generated by Vite)
- **Production URL**: `http://localhost:5000`

## Backend

### Entry Points
- **Flask App**: `backend/app.py`
- **Run Command**: `python app.py` (from `backend/` directory)
- **Port**: `5000`

### Game Discovery
Games are discovered by scanning these directories:
- `games/builtin/` - Built-in games
- `submodules/` - Git submodule games

Each game needs:
- `game_manifest.json` - In game root folder
- `backend/game.py` - Python game class
- Frontend component registered in `frontend/src/games/registry.ts`

## Game Structure

### Shape Smash Example

**Manifest:**
```
games/builtin/shape_smash/game_manifest.json
```

**Backend:**
```
games/builtin/shape_smash/backend/game.py
```

**Frontend:**
```
frontend/src/games/ShapeSmash.ts
```

**Registry Entry:**
```typescript
// In frontend/src/games/registry.ts
import { ShapeSmash } from './ShapeSmash';

private static games = new Map<string, GameComponentConstructor>([
  ['ShapeSmash', ShapeSmash],
]);
```

## Important Paths to Remember

| What | Where |
|------|-------|
| **Run Backend** | `backend/app.py` |
| **Run Frontend Dev** | `cd frontend && npm run dev` |
| **Build Frontend** | `cd frontend && npm run build` |
| **Backend Serves From** | `frontend/dist/` |
| **Add New Game** | `games/builtin/your_game/` or `submodules/your_game/` |
| **Register Frontend Game** | `frontend/src/games/registry.ts` |
| **Twitch Bot** | `backend/twitch_bot.py` |
| **Game Discovery** | `backend/game_loader.py` |

## Common Issues

### "404 Not Found" when accessing Flask app
- **Problem**: Frontend not built
- **Solution**: `cd frontend && npm run build`

### "Module not found" in browser console
- **Problem**: TypeScript compilation failed
- **Solution**: Check `npm run check` for errors

### Game not discovered
- **Problem**: Manifest missing or invalid
- **Solution**: Verify `game_manifest.json` exists and is valid JSON

### SocketIO not connecting
- **Problem**: Backend not running or CORS issue
- **Solution**: Start `backend/app.py` and check it's on port 5000

## Workflow

### Production Deployment
```bash
# 1. Install dependencies
cd backend && pip install -r requirements.txt
cd ../frontend && npm install

# 2. Build frontend
npm run build

# 3. Start backend (serves frontend from dist/)
cd ../backend && python app.py

# Open http://localhost:5000
```

### Development Mode
```bash
# Terminal 1 - Backend
cd backend
python app.py

# Terminal 2 - Frontend (with hot-reload)
cd frontend
npm run dev

# Open http://localhost:3000 (proxies to backend)
```
